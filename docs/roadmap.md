# Roadmap

## v0.1.0 - MVP Skeleton

- FastAPI backend.
- Streamlit frontend.
- Local document upload.
- LangChain document loading and splitting.
- Chroma persistence.
- Demo and OpenAI provider modes.
- Source-aware chat response.

## v0.2.0 - Knowledge Base Management

- Multiple knowledge bases.
- Delete and rebuild indexes.
- List indexed files.
- Configure retrieval parameters in UI.
- Add smoke tests for upload and chat APIs.

## v0.3.0 - Code Repository RAG

- Upload and parse zip archives.
- Ignore binary, dependency and build-output directories.
- Code-aware chunking by file, class and function.
- Show source path and line ranges.

## v0.4.0 - Local Model Support

- Ollama provider adapter.
- Qwen and Llama model presets.
- Local embedding model option.
- Provider comparison documentation.

## v1.0.0 - Resume-Ready Release

- Evaluation dataset.
- Retrieval and answer quality metrics.
- Latency and token usage reporting.
- Architecture diagram and demo screenshots.
- Deployment guide.
